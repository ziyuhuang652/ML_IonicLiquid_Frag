# References

`references.bib` is the bibliography used by
`manuscript/manuscript.tex`. Citation keys were preserved during the
reorganization.

`literature_notes/` contains comparison notes, digitization notes, and review
notes derived from the DFT/MM and ReaxFF reference papers.

`dft_literature/raw_dft_literature/` contains the locally retained DFT paper
PDF and extracted text/image assets used during manuscript preparation. These
files are reference/provenance material, not active plotting inputs.

Duplicate BibTeX keys were checked during cleanup; no duplicate keys were
found.
